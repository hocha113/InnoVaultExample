InnoVault Example is the official companion mod for the InnoVault API library. It ships runnable showcases for UIHandle, Actor, PRT, SaveContent, Override, TileProcessor, and more.

Documentation and reading paths: [url=https://innovault.wiki] innovault.wiki [/url]

Starting with v0.6 the mod uses the Vault Academy theme: the in-game manual opens a course catalog that links each demo to a Wiki chapter. Source is included in the workshop package.
